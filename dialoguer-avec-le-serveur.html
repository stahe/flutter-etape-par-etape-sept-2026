    9.1.1. Où est le serveur ?

    Pour un client web servi par le serveur lui-même, la question ne se pose pas : les requêtes partent vers la même origine que la page, avec une adresse relative ([/api/captcha]). Une application mobile n'a pas d'origine : il faut lui donner l'adresse complète du serveur. Et cette adresse dépend de l'endroit où tourne l'application :

    // =========================================================================
// lib/commun/config.dart - OÙ est le serveur JSON ?
// -------------------------------------------------------------------------
// La question ne se pose pas pour une application web servie par le
// serveur lui-même : les requêtes partent vers la MÊME origine que la page
// (une adresse relative, /api/...). Mais une application MOBILE n'a pas
// d'origine : il faut lui donner l'adresse complète du serveur.
//   - l'émulateur Android voit l'ordinateur qui le fait tourner à
//     l'adresse 10.0.2.2 (localhost, pour lui, c'est l'émulateur lui-même) ;
//   - un vrai téléphone, relié au même réseau Wi-Fi que l'ordinateur, doit
//     utiliser l'adresse de l'ordinateur sur ce réseau (192.168.1.20...) :
//     on la donne au lancement de l'application :
//         flutter run --dart-define=SERVEUR=http://192.168.1.20:8080 ...
//   - en développement web (flutter run -d chrome), le serveur de
//     développement de Flutter transmet les requêtes /api au serveur JSON
//     (fichier web_dev_config.yaml) : une adresse relative suffit ;
//   - sur un ordinateur (Windows, macOS, Linux) : localhost.
// =========================================================================

import 'package:flutter/foundation.dart';

// la valeur donnée par --dart-define=SERVEUR=..., '' par défaut.
// String.fromEnvironment est évaluée à la COMPILATION : c'est une constante
const _serveurImpose = String.fromEnvironment('SERVEUR');

class Config {
  // kIsWeb : vrai si l'application tourne dans un navigateur ;
  // defaultTargetPlatform : le système (android, iOS, windows...)
  static String urlServeur = _serveurImpose.isNotEmpty
      ? _serveurImpose
      : kIsWeb
      ? '' // même origine : adresses relatives
      : defaultTargetPlatform == TargetPlatform.android
      ? 'http://10.0.2.2:8080'
      : 'http://localhost:8080';
}
    • ligne 24 : une adresse donnée au lancement de l'application, par l'option [--dart-define] : [flutter run --dart-define=SERVEUR=http://192.168.1.20:8080 ...]. [String.fromEnvironment] est évaluée à la compilation : c'est une constante, '' si l'option n'est pas donnée ;
    • lignes 29-35 : sinon, une adresse par défaut, selon la plateforme. [kIsWeb] est vrai si l'application tourne dans un navigateur ; [defaultTargetPlatform] dit sur quel système elle tourne ([TargetPlatform.android], [TargetPlatform.windows]...) :
      • sur le web : une adresse relative (''), la même origine que l'application ;
      • sur l'émulateur [Android] : [http://10.0.2.2:8080]. L'émulateur est une machine à part entière, avec son propre réseau : pour lui, [localhost] c'est l'émulateur lui-même. L'adresse spéciale [10.0.2.2] désigne l'ordinateur qui le fait tourner ;
      • sur un ordinateur ([Windows]...) : [http://localhost:8080].

    Un vrai téléphone, relié au même réseau Wi-Fi que l'ordinateur du serveur, doit utiliser l'adresse de l'ordinateur sur ce réseau (la commande [ipconfig] de [Windows] la donne) : on la passe par [--dart-define]. Il faut aussi que le pare-feu de l'ordinateur laisse passer les connexions entrantes sur le port 8080.

    // =========================================================================
// lib/ex22_http/main.dart - une première requête HTTP vers le serveur
// -------------------------------------------------------------------------
// Le serveur JSON RdvMedecins doit être lancé (port 8080). On lui demande
// un captcha : GET /api/captcha -> { "id": "...", "svg": "<svg ...>" }.
//
//   - http.get(uri) : la fonction du paquet http qui envoie une requête
//     GET. Elle renvoie un Future de la réponse (http.Response) : son code
//     de statut (statusCode), ses entêtes (headers), son corps (body) ;
//   - jsonDecode(texte) : le corps JSON -> des objets Dart (Map, List...) ;
//   - l'adresse du serveur dépend de l'endroit où tourne l'application
//     (émulateur Android, téléphone, navigateur...) : cf. commun/config.dart ;
//   - trois états à afficher : en cours, réussi, en erreur ;
//   - l'image du captcha est du SVG : le paquet flutter_svg sait la dessiner.
// =========================================================================

import 'dart:convert';

import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';
import 'package:http/http.dart' as http;

import '../commun/config.dart';

void main() {
  runApp(
    MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const PageCaptcha(),
    ),
  );
}

class PageCaptcha extends StatefulWidget {
  const PageCaptcha({super.key});

  @override
  State<PageCaptcha> createState() => _PageCaptchaState();
}

class _PageCaptchaState extends State<PageCaptcha> {
  // ce que renvoie GET /api/captcha : un record
  ({String id, String svg})? _captcha;
  bool _enCours = true;
  String? _erreur;
  int _nbRequetes = 0;
  int _numeroDemande = 0; // le numéro de la dernière demande

  @override
  void initState() {
    super.initState();
    _charger(); // la première requête, dès l'apparition de l'écran
  }

  Future<void> _charger() async {
    final numero = ++_numeroDemande;
    setState(() {
      _enCours = true;
      _erreur = null;
    });
    try {
      final reponse = await http.get(Uri.parse('${Config.urlServeur}/api/captcha'));
      // http.get ne lance PAS d'exception pour une réponse d'erreur (4xx,
      // 5xx) : on teste le code de statut
      if (reponse.statusCode != 200) {
        throw Exception('le serveur a répondu ${reponse.statusCode} ${reponse.reasonPhrase}');
      }
      final json = jsonDecode(reponse.body) as Map<String, dynamic>;
      // la réponse d'une demande DÉPASSÉE (on a redemandé entre-temps), ou
      // arrivée après la fermeture de l'écran : on l'ignore
      if (!mounted || numero != _numeroDemande) return;
      setState(() {
        _captcha = (id: json['id'] as String, svg: json['svg'] as String);
        _nbRequetes++;
        _enCours = false;
      });
    } catch (e) {
      // pas de réponse du tout (serveur arrêté, mauvaise adresse...), ou erreur
      if (!mounted || numero != _numeroDemande) return;
      setState(() {
        _erreur = '$e';
        _captcha = null;
        _enCours = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    final captcha = _captcha;
    return Scaffold(
      appBar: AppBar(title: const Text('Exemple 22 - une première requête HTTP')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Text(
            'Serveur : ${Config.urlServeur.isEmpty ? '(même origine)' : Config.urlServeur}',
            style: const TextStyle(color: Colors.grey),
          ),
          const SizedBox(height: 12),
          if (_enCours) const LinearProgressIndicator(),
          if (_erreur != null)
            Card(
              color: Colors.red.shade50,
              child: Padding(
                padding: const EdgeInsets.all(12),
                child: Text(
                  "Impossible d'obtenir un captcha : $_erreur.\n"
                  'Le serveur JSON RdvMedecins est-il lancé (port 8080) ?',
                ),
              ),
            ),
          if (captcha != null && !_enCours) ...[
            // SvgPicture.string : dessiner une image SVG donnée sous forme de texte
            Container(
              padding: const EdgeInsets.all(4),
              decoration: BoxDecoration(
                border: Border.all(color: Colors.grey.shade300),
                borderRadius: BorderRadius.circular(6),
              ),
              child: SvgPicture.string(captcha.svg, height: 60),
            ),
            const SizedBox(height: 8),
            Text('id : ${captcha.id}', style: const TextStyle(fontFamily: 'RobotoMono', fontSize: 11)),
          ],
          const SizedBox(height: 12),
          Align(
            alignment: Alignment.centerLeft,
            child: FilledButton(onPressed: _enCours ? null : _charger, child: const Text('Autre image')),
          ),
          const SizedBox(height: 8),
          Text('$_nbRequetes requête(s) réussie(s)', style: const TextStyle(color: Colors.grey)),
        ],
      ),
    );
  }
}
    • ligne 21 : le paquet [http], le client HTTP de l'équipe de [Dart]. [as http] : ses fonctions s'utilisent préfixées ([http.get], [http.Response]), ce qui évite de confondre ses noms avec d'autres ;
    • lignes 44)? _captcha;}-48 : l'état : le captcha reçu (un record, ou [null]), les trois états d'une requête (en cours, en erreur, réussie), le nombre de requêtes réussies ;
    • lignes 51-53 : la première requête part dès l'apparition de l'écran ;
    • lignes 56-84 : la requête :
      • ligne 63 : [http.get] envoie une requête GET et renvoie un [Future<http.Response>] : la réponse, plus tard. [Uri.parse] fabrique l'adresse à partir d'une chaîne ;
      • lignes 66-67 : [http.get] ne lance PAS d'exception pour une réponse d'erreur (4xx, 5xx) : c'est une réponse comme une autre. On teste son code de statut ;
      • ligne 69 : [reponse.body] est le corps de la réponse, du texte ; [jsonDecode] le convertit en objets [Dart] : ici une [Map] ;
      • ligne 72 : la réponse d'une demande DÉPASSÉE (on a redemandé une image entre-temps), ou arrivée après la fermeture de l'écran, est ignorée (cf. exemple 19) ;
      • ligne 74 : le JSON est typé [dynamic] : on convertit chaque valeur dans son type, avec [as] ;
      • lignes {L:} catch (e) {}-82 : aucune réponse du tout (serveur arrêté, mauvaise adresse, réseau coupé) : [http.get] lance une exception, qu'on attrape, et qu'on affiche ;
    • ligne 102 : une barre de progression pendant la requête ;
    • ligne 122 : l'image du captcha est du SVG, sous forme de texte : [SvgPicture.string] (paquet [flutter_svg]) la dessine. Elle est fabriquée par NOTRE serveur, et ne contient rien qui vienne d'un utilisateur ;

    // =========================================================================
// lib/commun/client_http.dart - un client HTTP qui gère les COOKIES
// -------------------------------------------------------------------------
// Le serveur RdvMedecins dépose le jeton JWT dans un COOKIE (httpOnly).
// Dans un navigateur, c'est le navigateur qui range les cookies et les
// renvoie avec chaque requête : le code de l'application n'a rien à faire.
// Sur un téléphone, il n'y a PAS de navigateur : c'est à l'application de
// jouer son rôle, c'est-à-dire :
//   1. lire l'entête "Set-Cookie" de chaque réponse, et ranger les cookies ;
//   2. les renvoyer dans l'entête "Cookie" de chaque requête.
// Ce client HTTP le fait, en ENVELOPPANT le client du paquet http
// (http.BaseClient : il suffit d'écrire la méthode send). Les cookies sont
// aussi rangés sur l'appareil (shared_preferences) : on reste connecté
// quand on arrête puis relance l'application.
// Sur le web, il ne fait rien de plus que le client ordinaire : le
// navigateur interdit à l'application de lire ou d'écrire ces entêtes.
// =========================================================================

import 'dart:convert';

import 'package:flutter/foundation.dart';
import 'package:http/http.dart' as http;
import 'package:shared_preferences/shared_preferences.dart';

class ClientAvecCookies extends http.BaseClient {
  static const _cle = 'rdvmedecins.cookies';

  final http.Client _interne = http.Client();
  final SharedPreferences? _stockage;
  // nom du cookie -> sa valeur
  final Map<String, String> _cookies = {};

  ClientAvecCookies([this._stockage]) {
    // les cookies mémorisés lors d'une utilisation précédente
    final memorises = _stockage?.getString(_cle);
    if (memorises != null) {
      _cookies.addAll((jsonDecode(memorises) as Map<String, Object?>).cast<String, String>());
    }
  }

  @override
  Future<http.StreamedResponse> send(http.BaseRequest requete) async {
    if (!kIsWeb && _cookies.isNotEmpty) {
      // "rdvmedecins_jwt=eyJhbGci...; autre=valeur"
      requete.headers['cookie'] = [for (final MapEntry(:key, :value) in _cookies.entries) '$key=$value'].join('; ');
    }
    final reponse = await _interne.send(requete);
    final setCookie = reponse.headers['set-cookie'];
    if (!kIsWeb && setCookie != null) {
      _memoriser(setCookie);
    }
    return reponse;
  }

  // Set-Cookie: rdvmedecins_jwt=eyJ...; Max-Age=7200; Path=/api; Expires=Tue, 29 Sep 2026 ...; HttpOnly
  // (plusieurs cookies sont séparés par des virgules). On ne garde que le
  // nom et la valeur de chaque cookie ; une valeur vide (déconnexion) le supprime
  void _memoriser(String setCookie) {
    // un nom suivi de "=", en début d'entête ou après une virgule
    for (final m in RegExp(r'(?:^|,)\s*([^=;,\s]+)=([^;]*)').allMatches(setCookie)) {
      final nom = m[1]!;
      final valeur = m[2]!.trim();
      if (valeur.isEmpty) {
        _cookies.remove(nom);
      } else {
        _cookies[nom] = valeur;
      }
    }
    _stockage?.setString(_cle, jsonEncode(_cookies));
  }

  @override
  void close() => _interne.close();
}
    • ligne 25 : le paquet [http] permet d'envelopper son client : on hérite de [http.BaseClient], et il suffit d'écrire la méthode [send], par laquelle passent toutes les requêtes ([get], [post]...) ;
    • lignes 28-31 : le client enveloppé, le stockage de l'appareil (facultatif : [?]), et les cookies (nom -> valeur) ;
    • lignes 33-37 : à la création, les cookies mémorisés lors d'une utilisation précédente de l'application. On reste ainsi connecté quand on arrête puis relance l'application : c'est l'équivalent, sur un téléphone, du navigateur qui garde ses cookies d'une visite à l'autre ;
    • lignes 42-52 : chaque requête reçoit l'entête [Cookie] (« rdvmedecins_jwt=eyJhbGci...; autre=valeur »), puis on lit l'entête [Set-Cookie] de la réponse. [kIsWeb] : sur le web, on ne fait rien de plus que le client ordinaire, car le navigateur interdit à l'application de lire ou d'écrire ces entêtes (il s'en charge lui-même) ;
    • lignes 58-69 : l'entête [Set-Cookie]. Plusieurs cookies y sont séparés par des virgules, mais la date [Expires] contient elle-même une virgule (« Tue, 29 Sep 2026 ») : l'expression régulière ne retient qu'un nom suivi de [=], en début d'entête ou après une virgule. On ne garde que le nom et la valeur de chaque cookie ; une valeur vide (déconnexion : le serveur envoie [rdvmedecins_jwt=; Expires=Thu, 01 Jan 1970...]) supprime le cookie. [_stockage?.setString(...)] : l'appel n'a lieu que si [_stockage] n'est pas [null].

    Une gestion de cookies plus complète (domaines, chemins, dates d'expiration) existe dans des paquets ([cookie_jar], avec le client [dio]) ; la nôtre, de quelques lignes, suffit pour UN serveur. Remarque de sécurité : le jeton est ici rangé en clair sur l'appareil. Une application de production utiliserait le paquet [flutter_secure_storage] (cf. exemple 20).

    // =========================================================================
// lib/ex23_connexion/commande.dart - une ACTION, son état, son résultat
// -------------------------------------------------------------------------
// Une action asynchrone (se connecter, enregistrer...) a un état que
// l'écran doit montrer : est-elle EN COURS (bouton désactivé, indicateur) ?
// s'est-elle terminée par une ERREUR (message) ? C'est le modèle "Command"
// du guide d'architecture de Flutter, réduit à l'essentiel :
//
//     final connexion = Commande();
//     connexion.executer(() => seConnecter(...));    // lance l'action
//     connexion.enCours, connexion.erreur             // son état
//
// Une Commande est un ChangeNotifier : l'écran l'écoute (ListenableBuilder)
// et se redessine quand elle démarre et quand elle se termine.
// =========================================================================

import 'package:flutter/foundation.dart';

class Commande extends ChangeNotifier {
  bool _enCours = false;
  Object? _erreur;

  bool get enCours => _enCours;
  Object? get erreur => _erreur;

  // exécute l'action, si une autre n'est pas déjà en cours
  Future<void> executer(Future<void> Function() action) async {
    if (_enCours) return; // pas de double envoi (double appui sur le bouton)
    _enCours = true;
    _erreur = null;
    notifyListeners();
    try {
      await action();
    } catch (e) {
      _erreur = e; // l'erreur est GARDÉE, pour être affichée
    } finally {
      // finally : exécuté dans TOUS les cas, succès ou erreur
      _enCours = false;
      notifyListeners();
    }
  }

  void effacerErreur() {
    _erreur = null;
    notifyListeners();
  }
}

class ReponseEnErreur implements Exception {

  const ReponseEnErreur(this.reponse);

  List<dynamic> _medecins = [];
  Map<String, dynamic>? _captcha;
  bool _pret = false; // la vérification de départ est-elle terminée ?
  String? _erreurServeur;
  final _connexion = Commande();
  final _login = TextEditingController(text: 'admin');
  final _password = TextEditingController();
  final _reponseCaptcha = TextEditingController();

  @override
  void initState() {
    super.initState();
    _verifierSession();

  @override
  void dispose() {
    _connexion.dispose();

    _password.dispose();
    _reponseCaptcha.dispose();
    super.dispose();

  Uri _url(String chemin) => Uri.parse('${Config.urlServeur}/api$chemin');

  // une requête GET dont on veut le corps JSON ; une exception si ce n'est pas un 2xx
  Future<dynamic> _lire(String chemin) async {
    final reponse = await widget.client.get(_url(chemin));
    if (reponse.statusCode >= 300) throw ReponseEnErreur(reponse);
    return jsonDecode(utf8.decode(reponse.bodyBytes));
  }

  // un POST avec un corps JSON
  Future<http.Response> _poster(String chemin, Object corps) {
    return widget.client.post(
      _url(chemin),
      headers: {'content-type': 'application/json'}, // le corps est du JSON
      body: jsonEncode(corps),
    );

    final captcha = await _lire('/captcha') as Map<String, dynamic>;
    _reponseCaptcha.clear();
    if (mounted) setState(() => _captcha = captcha);

      await _chargerMedecins();

        await _chargerCaptcha();
      } else {
        _erreurServeur = 'Le serveur a répondu ${e.reponse.statusCode}.';
      }
    } catch (_) {
      _erreurServeur = 'Le serveur JSON RdvMedecins est-il lancé (${Config.urlServeur}) ?';

enum Role { admin, doctor, user }

  final int version;

  final String prenom;
  final String nom;
  final String? login; // seulement pour l'ADMIN

// lib/commun/erreur_api.dart - UNE classe pour toutes les erreurs de l'API
// -------------------------------------------------------------------------
// Toutes les réponses d'erreur du serveur RdvMedecins ont la même forme :
//   { "statusCode": 409, "cle": "ERRORS.LOGIN_TAKEN", "params": {...}, "champs": {...} }
// Mais une requête peut aussi échouer AUTREMENT : pas de réponse du tout
// (réseau coupé, serveur arrêté, mauvaise adresse), ou une réponse qui ne
// vient pas de notre serveur (une page d'erreur d'un proxy). On convertit
// tout cela en UNE classe, ErreurApi, qui porte la clé de traduction
// envoyée par le serveur (et, s'il y en a, ses paramètres et l'erreur de
// chaque champ).
// =========================================================================

import 'dart:convert';

import 'package:http/http.dart' as http;

// "implements Exception" : un objet qu'on peut lancer (throw) et attraper (catch)
class ErreurApi implements Exception {
  final int statusCode; // 0 : le serveur n'a pas répondu
  final String cle; // ex : 'ERRORS.LOGIN_TAKEN'
  final Map<String, String> params;
  final Map<String, String> champs;

  const ErreurApi(this.statusCode, this.cle, {this.params = const {}, this.champs = const {}});

  // une réponse d'erreur (4xx, 5xx) -> une ErreurApi
  factory ErreurApi.depuisReponse(http.Response reponse) {
    Object? corps;
    try {
      corps = jsonDecode(utf8.decode(reponse.bodyBytes));
    } on FormatException {
      corps = null; // pas du JSON : ce n'est pas notre serveur qui a répondu
    }
    // le "filtrage" (pattern matching) d'une Map : si le corps a une clé
    // "cle" de type String, elle est rangée dans la variable cle
    if (corps case {'cle': final String cle}) {
      final json = corps as Map<String, Object?>;
      return ErreurApi(reponse.statusCode, cle, params: _chaines(json['params']), champs: _chaines(json['champs']));
    }
    // pas de clé : le proxy ou le réseau ont répondu à sa place
    return ErreurApi(
      reponse.statusCode,
      reponse.statusCode >= 500 ? 'ERRORS.SERVER_UNREACHABLE' : 'ERRORS.SERVER_ERROR',
    );
  }

  // un objet JSON { "nom": "ERRORS..." } -> Map<String, String> (vide sinon)
  static Map<String, String> _chaines(Object? json) =>
      json is Map<String, Object?> ? {for (final e in json.entries) e.key: '${e.value}'} : const {};

  @override
  String toString() => '$statusCode $cle';
}

    • lignes 19-23 : un statut (0 : pas de réponse), une clé de traduction, ses paramètres, l'erreur de chaque champ ;

// lib/commun/api.dart - des requêtes vers l'API, en une ligne
// -------------------------------------------------------------------------
// Dans l'exemple 23, chaque requête répétait les mêmes gestes : adresse du
// serveur, préfixe /api, entête JSON, test du code de statut, lecture du
// corps d'erreur... On les regroupe ici :
//
//   final json = await api.get('/medecins');
//   await api.post('/rendez-vous', {'jour': jour, 'idCreneau': 3});
//
//   - en cas de succès, le Future renvoie le corps JSON, DÉCODÉ (des Map,
//     des List, des String, des nombres...) ;
//   - en cas d'échec, il se termine par une ErreurApi.
// Toutes les requêtes passent par la méthode requete : c'est l'endroit où
// l'on traiterait un problème COMMUN à toutes (cf. l'étude de cas et la
// réponse 401). Utilisé par les exemples 24 et 25.
// =========================================================================

import 'dart:convert';

import 'package:http/http.dart' as http;

import 'config.dart';
import 'erreur_api.dart';

class Api {
  final http.Client _client;

  Api(this._client);

  Future<Object?> requete(String methode, String url, [Object? corps]) async {
    final requete = http.Request(methode, Uri.parse('${Config.urlServeur}/api$url'));
    if (corps != null) {
      // un corps JSON (le serveur refuse un POST qui n'en est pas un)
      requete.headers['content-type'] = 'application/json';
      requete.body = jsonEncode(corps);
    }
    final http.Response reponse;
    try {
      // send envoie la requête ; fromStream attend le corps complet de la réponse
      reponse = await http.Response.fromStream(await _client.send(requete));
    } catch (_) {
      // AUCUNE réponse (réseau, serveur arrêté, mauvaise adresse)
      throw const ErreurApi(0, 'ERRORS.SERVER_UNREACHABLE');
    }
    if (reponse.statusCode >= 400) {
      throw ErreurApi.depuisReponse(reponse);
    }
    return reponse.bodyBytes.isEmpty ? null : jsonDecode(utf8.decode(reponse.bodyBytes));
  }

  Future<Object?> get(String url) => requete('GET', url);
  // un POST a toujours un corps JSON : {} par défaut
  Future<Object?> post(String url, [Object corps = const {}]) => requete('POST', url, corps);
  Future<Object?> put(String url, Object corps) => requete('PUT', url, corps);
  Future<Object?> delete(String url, [Object? corps]) => requete('DELETE', url, corps);
}
    • lignes 31-49 : TOUTES les requêtes passent par cette méthode : l'adresse du serveur et le préfixe [/api], le corps en JSON, l'envoi ([_client.send], puis [http.Response.fromStream] qui attend le corps complet), les erreurs converties en [ErreurApi], le corps de la réponse décodé. C'est l'endroit où l'on traiterait un problème commun à toutes les requêtes (cf. l'étude de cas et la réponse 401) ;
    • lignes 52-56 : quatre raccourcis. Un POST a toujours un corps JSON : [{}] par défaut.

import 'package:flutter/foundation.dart';

import '../commun/erreur_api.dart';
import '../commun/types.dart';
import 'rdvmedecins.dart';

String _deuxChiffres(int n) => n.toString().padLeft(2, '0');
String formatJour(DateTime d) => '${d.year}-${_deuxChiffres(d.month)}-${_deuxChiffres(d.day)}';

class AgendaModele extends ChangeNotifier {
  final RdvMedecins _rdvmedecins;

  AgendaModele(this._rdvmedecins);

  // ---- l'état ----
  Utilisateur? utilisateur;
  List<Personne> medecins = [];
  List<Personne> clients = [];
  int? idMedecin;
  String jour = formatJour(DateTime.now().add(const Duration(days: 1))); // demain
  int? idClient;
  Agenda? agenda;
  bool chargement = false;
  ({bool succes, String texte})? message;

  final Map<String, Agenda> _cache = {};
  int _numeroLecture = 0;

  // ---- des valeurs calculées ----
  bool get connecte => utilisateur != null;
  bool get gestionnaire => connecte && utilisateur!.role != Role.user;

  // ---- les actions ----
  Future<void> changerUtilisateur(Utilisateur? u) async {
    utilisateur = u;
    medecins = [];
    clients = [];
    agenda = null;
    idMedecin = null;
    _cache.clear(); // les droits ont changé : on oublie tout
    notifyListeners();
    if (u == null) return;
    medecins = await _rdvmedecins.getMedecins();
    if (gestionnaire) clients = await _rdvmedecins.getClients(); // un USER recevrait 403
    notifyListeners();
  }

  void choisirMedecin(int id) {
    idMedecin = id;
    message = null;
    _lireAgenda();
  }

  void choisirJour(DateTime d) {
    jour = formatJour(d);
    message = null;
    _lireAgenda();
  }

  void choisirClient(int? id) {
    idClient = id;
    notifyListeners();
  }

  Future<void> reserver(CreneauAgenda c) =>
      _agir(() => _rdvmedecins.reserver(jour, c.id, gestionnaire ? idClient : null), 'Créneau ${c.horaire} réservé.');

  Future<void> annuler(CreneauAgenda c) =>
      _agir(() => _rdvmedecins.annuler(c.idRv!), 'Rendez-vous de ${c.horaire} annulé.');

  // une action, puis TOUJOURS une relecture de l'agenda : c'est le SERVEUR qui fait foi
  Future<void> _agir(Future<void> Function() action, String succes) async {
    try {
      await action();
      message = (succes: true, texte: succes);
    } on ErreurApi catch (e) {
      message = (succes: false, texte: '$e');
    }
    await _lireAgenda();
  }

  Future<void> _lireAgenda() async {
    final id = idMedecin;
    if (id == null) return;
    final cle = '$id/$jour';
    final numero = ++_numeroLecture;
    // le cache d'abord (ou rien), puis la lecture
    agenda = _cache[cle];
    chargement = true;
    notifyListeners();
    try {
      final lu = await _rdvmedecins.getAgenda(id, jour);
      if (numero != _numeroLecture) return; // une lecture plus récente a été lancée
      agenda = _cache[cle] = lu;
    } on ErreurApi catch (e) {
      if (numero != _numeroLecture) return;
      agenda = null;
      message = (succes: false, texte: '$e');
    }
    chargement = false;
    notifyListeners();
  }
}

class _PageClientsState extends State<PageClients> {
  late final Api _api = context.read<Api>();
  Utilisateur? _utilisateur;
  List<Personne> _clients = [];

  // le formulaire : _idEdite == null -> création, sinon modification
  int? _idEdite;
  int _version = 0;
  String _titre = 'Mr';
  final _textes = {
    for (final c in [Champ.prenom, Champ.nom, Champ.login, Champ.password]) c: TextEditingController(),
  };
  // l'erreur de chaque champ (une CLÉ de traduction), renvoyée par le serveur
  Map<String, String> _erreurs = {};
  // le message général de la dernière erreur, et celui d'un succès (clé + paramètres)
  ErreurApi? _erreurPage;
  ({String cle, Map<String, String> params})? _succes;
  // l'envoi au serveur : une Commande (exemple 23), qui dit s'il est en cours
  final _envoi = Commande();

  bool get _estAdmin => _utilisateur?.role == Role.admin;

  @override
  void dispose() {
    for (final c in _textes.values) {
      c.dispose();
    }
    _envoi.dispose();
    super.dispose();
  }

  Future<void> _recharger() async {
    final clients = Personne.liste(await _api.get('/clients'));
    if (mounted) setState(() => _clients = clients);
  }

  Future<void> _surConnexion(Utilisateur? u) async {
    setState(() {
      _utilisateur = u;
      _clients = [];
    });
    if (u?.role == Role.admin) await _recharger();
  }

  void _effacerMessages() {
    _erreurs = {};
    _erreurPage = null;
    _succes = null;
  }

  void _nouveau() {
    setState(() {
      _idEdite = null;
      _version = 0;
      _titre = 'Mr';
      for (final c in _textes.values) {
        c.clear();
      }
      _effacerMessages();
    });
  }

  void _editer(Personne c) {
    setState(() {
      _idEdite = c.id;
      // la VERSION lue avec la fiche repart avec la modification : si quelqu'un
      // a modifié la fiche entre-temps, le serveur répondra 409 CONCURRENT_UPDATE
      _version = c.version;
      _titre = c.titre;
      _textes[Champ.prenom]!.text = c.prenom;
      _textes[Champ.nom]!.text = c.nom;
      _textes[Champ.login]!.text = c.login ?? '';
      _textes[Champ.password]!.clear();
      _effacerMessages();
    });
  }

  Future<void> _enregistrer() async {
    setState(_effacerMessages);
    final saisie = {
      'titre': _titre,
      for (final MapEntry(key: champ, value: c) in _textes.entries) champ.name: c.text,
      'version': _version,
    };
    try {
      final client = Personne.depuisJson(
        _idEdite == null ? await _api.post('/clients', saisie) : await _api.put('/clients/$_idEdite', saisie),
      );
      final cle = _idEdite == null ? 'FORM.AJOUTE' : 'FORM.MODIFIE';
      _nouveau(); // formulaire vidé, messages effacés...
      // ... sauf celui-ci
      setState(
        () => _succes = (cle: cle, params: {'nom': '${client.prenom} ${client.nom}', 'login': client.login ?? ''}),
      );
      await _recharger();
    } on ErreurApi catch (e) {
      setState(() {
        _erreurPage = e; // le message général
        _erreurs = e.champs; // l'erreur de chaque champ
      });
    }
  }

  Future<void> _supprimer(Personne c) async {
    final t = context.read<Traductions>().t;
    final nom = '${c.prenom} ${c.nom}';
    final oui = await confirmer(context, t('FORM.CONFIRMER_SUPPRESSION', {'nom': nom}));
    if (!oui || !mounted) return;
    setState(_effacerMessages);
    try {
      await _api.delete('/clients/${c.id}');
      setState(() => _succes = (cle: 'FORM.SUPPRIME', params: {'nom': nom}));
    } on ErreurApi catch (e) {
      setState(() => _erreurPage = e);
    }
    await _recharger();
  }
